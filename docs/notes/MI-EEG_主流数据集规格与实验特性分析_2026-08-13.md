# MI-EEG 主流数据集规格与实验特性分析

> 记录日期：2026-08-13  
> 用途：留存本轮关于 MI-EEG 主流公开数据集规格、任务差异、模型反应与实验用途的讨论结论。  
> 范围：DBConformer、DSAINet 涉及的主要 MI 数据集，以及 XW-Stroke、2019-Stroke。

---

## 1. 核心结论

1. **MI-EEG 数据集之间的差异不仅是“导联数不同”**。被试数、类别数、会话数、单被试 trial 数、采样率、健康/卒中人群，以及具体评估协议，都会显著改变模型表现。
2. **同一个数据集名称在不同论文中可能对应不同实验对象**。尤其是 BNCI2014001 和 BNCI2014004，不同论文可能使用不同会话、类别、时间窗和预处理，因此准确率不能脱离协议直接比较。
3. **空间建模收益具有明显的数据集依赖性**：
   - 22、59、64 通道的数据集能够提供较丰富的空间关系；
   - BNCI2014004 仅 3 通道，复杂空间注意力、图结构或通道关系模块的信息上限较低；
   - 因此“空间增强在 BNCI2014001 有正信号、在 BNCI2014004 无收益甚至退化”是合理现象，不应首先归因于代码错误。
4. **类别数直接影响任务难度和准确率含义**。左右手二分类和完整四分类不应直接横向比较；同一数据集的二分类结果通常显著高于四分类。
5. **被试数与单被试样本量反映不同的泛化风险**：
   - Zhou2016 被试极少，更适合检验少源被试条件下的泛化；
   - OpenBMI、PhysioNet-MI 被试数多，更适合检验大规模跨被试泛化；
   - 卒中数据还额外包含病理异质性。
6. **采样率决定卷积核、patch、时间窗的物理尺度**。250 Hz 下的模型超参数不能机械复制到 512 Hz、1000 Hz 数据集。
7. 当前论文如果强调多域特征学习、双分支或空间-频谱建模，推荐的核心数据集组合为：
   - **BNCI2014001：主开发与完整消融**
   - **BNCI2014004：稀疏导联压力测试**
   - **OpenBMI：大规模跨被试/跨会话泛化**
   - **XW-Stroke：临床跨患者扩展**

## 4. 各数据集的主要实验意义

### 4.1 BNCI2014001：主开发数据集

BNCI2014001 在当前论文中最适合作为主开发数据集。22 通道能够提供较完整的运动区空间信息，同时样本规模和被试数又没有大到使实验成本失控。

需要始终区分两个常见口径：

- **DBConformer 原生口径**：第一会话、左右手二分类、1296 trials，并使用 EA；
- **DSAINet 口径**：双会话、完整四分类、5184 trials，严格 subject-independent 评估。

因此，同为 BNCI2014001 的 70%～80% 二分类结果与 50%～60% 四分类 LOSO 结果不能直接比较。

对当前研究而言，它最适合：
- 模型主结构开发；
- 分支消融；
- 空间 / 频率 / 时间模块消融；
- 融合方式比较；
- 多 seed 稳定性与统计显著性检验。

### 4.2 BNCI2014004：稀疏通道压力测试

BNCI2014004 最大特点是只有 **3 个 EEG 通道**。这意味着空间模块可以利用的关系数量非常有限。

对于 channel-token Transformer、图结构、空间注意力等模型：
- 3 个 token 的关系学习容量天然有限；
- 增加复杂空间模块可能主要增加参数，而不是增加有效信息；
- 时间和频率特征往往比复杂空间交互更重要。

因此，如果一个空间增强模块在 BNCI2014001 有收益、在 BNCI2014004 持平或轻微退化，这种结果本身是可以解释的，不必要求所有数据集都保持同等提升。

### 4.3 Zhou2016：少源被试泛化

Zhou2016 只有 4 名被试，因此 LOSO 时每一折只剩 3 名源被试。

它更适合回答：
- 模型是否严重依赖大量源被试；
- 少数源被试时模型是否容易过拟合个体；
- 被试间标准差是否明显增大。

不适合仅凭一个总体平均值证明模型具有普适性。

### 4.4 Blankertz2007：高密度空间建模

Blankertz2007 有 59 通道，空间拓扑丰富，非常适合：
- 空间注意力；
- 图神经网络；
- 协方差 / 黎曼方法；
- 通道关系建模；
- 空间可解释性分析。

但其被试数只有 7，并且不同被试的二分类动作语义不完全一致，所以做跨被试实验时必须严格核查标签定义。

### 4.5 BNCI2014002：采样率与任务变化验证

BNCI2014002 为 512 Hz，明显高于 BNCI2014001 / 004 的 250 Hz。

同一个长度为 64 点的卷积核：
- 250 Hz 时约覆盖 256 ms；
- 512 Hz 时约覆盖 125 ms。

因此，模型跨数据集迁移时应优先按“秒”而不是“采样点”理解 kernel、pool、patch 和时间窗口。

### 4.6 OpenBMI：大规模跨被试 / 跨会话泛化

OpenBMI 有 54 名被试和两个会话，是当前这些标准公开数据中非常有价值的大规模泛化 benchmark。

它尤其适合：
- 跨被试泛化；
- 跨会话鲁棒性；
- 模型稳定性；
- 多域分支是否在较大样本下仍有稳定收益；
- 检验结果是否只是 BNCI2014001 小样本上的偶然现象。

对于当前多域特征学习方向，OpenBMI 的论文验证价值明显高于继续堆叠多个 9 人小数据集。

### 4.7 PhysioNet-MI：大规模、高通道、四分类验证

PhysioNet-MI 被试数达到 109，EEG 通道为 64，并且可构造四分类 MI 任务。

它同时具备：
- 大规模被试；
- 高密度通道；
- 更复杂类别空间。

适合用来检验：
- 高通道空间建模是否有效；
- 四分类下模型是否仍能稳定工作；
- 大规模训练下创新模块的收益是否仍然存在。

但其采集范式和原始采样率与 BCI Competition 数据不同，因此更适合作为泛化验证，而不是直接跨数据集无缝迁移。

### 4.8 XW-Stroke：临床跨患者扩展

XW-Stroke 的困难不仅是样本少，更重要的是患者之间存在明显病理异质性：
- 病灶位置不同；
- 损伤程度不同；
- 恢复阶段不同；
- 左右半球典型 ERD / ERS 规律可能被破坏；
- 健康人的固定 C3 / C4 空间先验可能不稳定成立。

因此它更适合检验：
- 跨患者泛化；
- 频率 / 节律建模；
- 病理条件下的鲁棒特征；
- 健康人空间先验是否能够迁移。

当前项目中，论文标称 30 通道，但实际已核验的是 **29 个有效通道**，后续空间图结构应以当前实际数据契约为准。

### 4.9 2019-Stroke：高密度卒中数据，但暂不宜作为首批空间实验

2019-Stroke 有 63 通道，理论上非常适合高密度空间建模，但当前项目仍缺少可靠的通道顺序 / `channel_info` 证据。

因此当前边界应为：
- 普通时序 CNN / Mamba 类模型可以继续研究；
- 依赖真实电极拓扑的 GNN、spatial patch、脑区分组模型暂不应将结果写成生理空间建模证据；
- 等通道顺序和数据契约核验完成后，再进入正式高密度卒中验证。

## 5. 为什么不同数据集会对模型产生不同反应

### 5.1 通道数决定空间建模的信息上限

可粗略理解为：

- **3 通道**：只能描述极粗粒度的左右运动区差异；
- **14–22 通道**：能够学习运动区及周边通道关系；
- **59–64 通道**：能够学习更丰富的空间拓扑、功能连接和协方差结构。

因此空间模块的收益通常不是“模块越复杂越好”，而是受到数据空间采样密度的限制。

### 5.2 类别数改变任务难度

随机水平大致为：

- 二分类：50%
- 三分类：33.3%
- 四分类：25%

但实际差异不仅来自随机水平。左右手二分类主要依赖左右半球差异，而四分类还需要同时区分双脚、舌头等更复杂空间模式。

因此，不能用二分类 75% 与四分类 62% 直接说明前者模型更强。

### 5.3 被试数与单人样本量影响不同类型的泛化

- **Zhou2016**：被试少、单人样本较多，更容易学到个体模式；
- **OpenBMI / PhysioNet-MI**：被试多，更适合检验真正的跨被试泛化；
- **XW-Stroke / 2019-Stroke**：患者异质性会进一步放大跨被试差异。

### 5.4 会话数决定是否包含 session drift

单会话训练和多会话训练是不同问题。多会话会引入：
- 电极重新佩戴差异；
- 日间状态变化；
- 阻抗变化；
- 生理状态变化；
- session drift。

因此，同一数据集只使用第一会话与使用全部会话，不能视为完全相同的任务。

### 5.5 采样率改变模型物理感受野

kernel size、patch size 和 pooling window 都应转换成物理时间进行理解。

例如 64 点卷积核：
- 250 Hz：256 ms
- 512 Hz：125 ms
- 1000 Hz：64 ms

所以跨数据集迁移时，如果仍固定相同采样点参数，模型实际建模的生理时间尺度会发生明显变化。

## 6. 按研究用途归类

| 研究目的 | 最合适的数据集 | 原因 |
|---|---|---|
| **主模型开发与消融** | BNCI2014001 | 通道数、样本量和文献可比性比较均衡 |
| **稀疏导联鲁棒性** | BNCI2014004 | 只有 3 通道，可以直接检验空间模块是否过度设计 |
| **高密度空间建模** | Blankertz2007、PhysioNet-MI | 59–64 通道，空间拓扑关系丰富 |
| **大规模跨被试泛化** | OpenBMI、PhysioNet-MI | 分别有 54 和 109 名被试 |
| **少源被试泛化** | Zhou2016 | 只有 4 名被试，LOSO 训练源域极少 |
| **不同采样率适配** | BNCI2014002、OpenBMI | 原始采样率为 512 和 1000 Hz |
| **卒中临床扩展** | XW-Stroke | 当前已有 24 人、29 通道的可验证数据链路 |
| **后续高密度卒中验证** | 2019-Stroke | 通道多，但需先解决通道顺序和协议核验 |

## 7. 对当前论文实验设计的建议

### 推荐核心组合

| 论文角色 | 数据集 | 主要回答的问题 |
|---|---|---|
| **主开发数据集** | BNCI2014001 | proposed 是否有效；多域 / 双分支 / 空间建模是否真正带来收益 |
| **稀疏通道压力测试** | BNCI2014004 | proposed 是否过度依赖丰富空间输入；空间模块在 3 通道下是否需要降级 |
| **大规模泛化验证** | OpenBMI | 提升是否能跨更多被试、更多会话复现，而不是 9 人小样本偶然现象 |
| **临床扩展验证** | XW-Stroke | 健康人建立的机制能否迁移到病理分布和跨患者场景 |

### 对多域 / 双分支论文叙事的建议

不必要求 proposed 在所有数据集上获得几乎相同的增益。更有价值的结果模式是：

1. 在 BNCI2014001、OpenBMI 等中高通道数据上，空间-频谱或多域模块获得稳定正收益；
2. 在 BNCI2014004 上，空间模块收益减弱或通过自适应机制自动降低贡献，但整体性能不显著退化；
3. 在 XW-Stroke 上，时间 / 频率相关路径比固定健康人空间先验更可靠；
4. 不同数据集上的收益差异能够由通道密度、任务类别、会话差异和人群差异解释。

这类结果比“所有数据集统一提升约 1%”更能支撑多域特征学习的研究叙事。

## 8. 实验与写作时必须保留的口径边界

1. **禁止只按数据集名称直接比较论文数值**，必须同时确认：
   - 会话范围；
   - 类别空间；
   - 时间窗；
   - 采样率；
   - 预处理；
   - EA / 标准化；
   - 被试内 / 跨被试；
   - 模型选择方式。
2. **BNCI2014001** 的 DBConformer 原生二分类结果不能与 DSAINet 双会话四分类 LOSO 直接比较。
3. **BNCI2014004** 的第一会话 1080 trials 口径与全 5 会话约 6520 trials 口径应分开记录。
4. **OpenBMI** 原始为高密度 62 通道 / 1000 Hz，但不少论文会筛选运动区通道并重采样，因此应记录“原始规格”和“实际模型输入规格”。
5. **XW-Stroke** 当前工程数据应以实际核验的 29 通道为准，不应为了对齐论文描述强行写成 30 通道。
6. **2019-Stroke** 在通道顺序未核验前，不将依赖真实拓扑的空间模型结果写成可靠生理空间证据。

## 9. 当前阶段性判断

对当前 MI-EEG 结构创新工作而言，**数据集不应只是用来“多跑几个 benchmark”**，而应承担不同的验证角色：

- BNCI2014001：证明 proposed 的基本有效性；
- BNCI2014004：证明 proposed 不依赖高通道空间信息；
- OpenBMI：证明 proposed 在大规模跨被试 / 跨会话条件下仍有泛化价值；
- XW-Stroke：证明 proposed 对临床病理分布具有一定扩展潜力。

因此，后续设计模型时应同时考虑：

> **模型结构是否能够随数据空间密度、采样率、任务复杂度和人群差异自适应，而不是假设所有 MI-EEG 数据集具有相同的数据结构。**

这也是后续多域特征学习、双分支职责划分和融合机制设计中值得保留的核心研究判断。
